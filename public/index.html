Dự án của bạn

Mỗi dự án có bộ AGENTS.md, rules, skills, hooks riêng và port không trùng nhau.

Tạo dự án mới

Điền thông tin → Xem trước file sẽ tạo → Tạo. Không có file nào bị ghi đè nếu bạn không đồng ý.

1 Thông tin
Đường dẫn thư mục có sẵn *
2 Ngôn ngữ / Stack
3 Môi trường & Port
4 Mức cấu hình AI

Xem trước

Bấm Xem trước để thấy cây file, trạng thái port và cảnh báo trước khi ghi ra đĩa.

Môi trường máy

Công cụ cần để chạy dự án trên máy này. Cài qua winget và tự thêm vào biến môi trường PATH.

Sang máy mới: chạy setup.bat trước (không cần Node.js) — nó cài Node.js, Git và hỏi từng công cụ còn lại, rồi mở app.

Thư viện template

Kho gốc rules / skills / agents / hooks. Sửa file trong thư mục templates/ để thay đổi cho các dự án tạo sau.
