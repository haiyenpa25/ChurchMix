# Security Audit

1. Map trust boundaries and privileged operations.
2. Identify attacker-controlled data.
3. Trace validation, authorization, storage, transport, and output encoding.
4. Review: authentication; authorization / IDOR; SQL/NoSQL injection; command injection; path traversal; SSRF; XSS/template injection; CSRF; secrets in code and logs; insecure defaults; dependency risks; unsafe file upload; cryptographic misuse.
5. Rank findings by exploitability and impact.
6. Recommend the smallest safe remediation.
7. Verify remediation with focused tests or security checks when possible.

Never weaken a security control merely to satisfy a test.
