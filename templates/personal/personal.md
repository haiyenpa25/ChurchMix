- Communicate with the user in Vietnamese; keep code identifiers, commit messages, and code comments in English unless the project already uses Vietnamese.
- User-facing UI text is Vietnamese with full diacritics unless the project specifies otherwise.
- Ask before adding a new dependency or changing the project structure.
- Prefer small, reviewable changes over large rewrites.
- When something is ambiguous, ask a short clarifying question instead of guessing.
